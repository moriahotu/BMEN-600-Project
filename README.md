# BMEN-600-Project
1. Endometriosis fibrosis / macrophage–fibroblast signalling
We want to investigate which macrophage–fibroblast signalling pathways are reproducibly dysregulated across independent human single-cell endometriosis datasets, using GSE213216 and GSE179640. Our biggest uncertainty is whether comparable macrophage and fibroblast populations are represented across both datasets well enough to validate the same signalling pathways independently.
GSE213216: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE213216
GSE179640: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE179640
2. Breast implants / MAUDE data quality
We want to investigate whether missing patient demographic information in FDA MAUDE breast-implant adverse-event reports differs systematically by event type, manufacturer and reporting source. Our biggest uncertainty is whether demographic fields are captured consistently enough across reporting pathways and years to separate real missingness patterns from changes in MAUDE reporting practices.
MAUDE: https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfmaude/textsearch.cfm
openFDA API: https://open.fda.gov/apis/device/event/
